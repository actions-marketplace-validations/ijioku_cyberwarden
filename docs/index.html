One shop, scanned twice

CyberWarden is a free security scanner for websites and AI coding setups. Below are its real reports on a small online shop: first with the mistakes a rushed developer (or an AI) often makes, then after fixing them.

Before: the broken shop

D50 / 100
4 critical 10 high 9 medium
  • SQL injection on the product page
  • Passwords stored with a fast, crackable hash
  • Payment amount and "paid" status taken from the browser
  • A secret key visible in the page source
Open the Grade D report

After: the same shop, fixed

A100 / 100
0 problems found
  • Database queries use safe parameters
  • Passwords hashed with bcrypt
  • Prices looked up on the server, and Paystack webhooks signature-checked
  • Secrets kept in environment variables
Open the Grade A report

Both shops are made-up sample apps from the examples folder. The reports are real CyberWarden output, unedited apart from the folder name. Each report is one offline file: findings with before-and-after fixes, a fix plan, and the list of every check that ran.
